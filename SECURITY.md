# Security Policy

## Supported versions

Codex Limits is currently in its initial development series. Security fixes are
provided for the latest release only.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's
[private vulnerability reporting form](https://github.com/EmilsValdmanis/codex-limits/security/advisories/new)
to send a confidential report. Include the affected version, reproduction
steps, impact, and any suggested remediation.

You should receive an acknowledgement within seven days. Confirmed issues will
be coordinated privately until a fix and disclosure plan are ready.
